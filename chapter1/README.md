# Chapter 1 – Introduction to Artificial Intelligence in Agriculture

Bentham Books edited volume: *Artificial Intelligence in Agriculture: Scientific Principles, Applications, and Future Directions*.

## Files
- `Chapter1_Introduction_to_AI_in_Agriculture_Bentham.docx`: the chapter manuscript (MS Word, Times New Roman 12 pt, 1.5 spacing, A4)
- `figures/`: Figs. 1–4 as separate 300-dpi PNG files, as Bentham requires for submission
- `build_chapter1.js`: rebuilds the .docx (`node build_chapter1.js`)
- `make_figures.py`: regenerates the figures (`python3 make_figures.py figures`)

## Structure (Bentham chapter format)
Title → Author and affiliation → Corresponding author and e-mail → Abstract (≤250 words, no citations) → Keywords (10, alphabetical) → Body (Introduction … Conclusion) → List of Abbreviations → Acknowledgements → Consent for Publication → Conflict of Interest → References (54, numbered in order of citation, in Bentham journal style with DOIs).

## Before submission
1. Check every reference and DOI against the original source.
2. Add co-authors or funding to the title page and Acknowledgements if needed.
3. Run a plagiarism check (iThenticate/Turnitin), and sign and attach the Bentham copyright letter.
4. Get the latest chapter template from the editors and apply it if they provide one.
