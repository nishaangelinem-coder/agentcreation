\section*{Highlights}
\begin{itemize}
\item Dual-port, $0.054\lambda_0$-thick SIW slot array for the 28 GHz 5G band on a single RT/duroid 5880 layer.
\item Resonant slits in the shared top wall, dimensioned by characteristic-mode analysis, raise the port isolation.
\item Full-wave slot characterisation shows an order-of-magnitude larger conductance than the Stegen formula in thin SIW.
\item Open-source Numba FDTD + RWG MoM/characteristic-mode environment; no commercial EM software needed.
\item All solvers, scripts and data are released for full reproducibility.
\end{itemize}
